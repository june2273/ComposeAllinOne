# --- 버전을 고정해야 하는 것 -------------------------------------------------
#
# setuptools 81에서 `pkg_resources`가 제거됐는데 `resampy`(librosa →
# basic-pitch)가 아직 그것을 import한다. 최신 setuptools를 쓰면 f0 추출이
# `ModuleNotFoundError: No module named 'pkg_resources'`로 죽는다.
#
# **이 사고는 조용하다** — import 시점이 아니라 실행 시점에 터지므로 서버는
# 멀쩡히 뜨고 /health도 초록으로 나온다. 그래서 app/melody.py에 기동 자가진단을
# 따로 두었다(`selftest`). 이 핀과 그 진단은 같은 사고를 앞뒤로 막는 것이다.
setuptools<81
